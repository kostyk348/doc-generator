## [Unreleased]

### Added

- **ГОСТ-документы на фирменном бланке** (`431b806`): шапка с реквизитами и логотипом, типы документов
  (письма, служебные записки, приказы, уведомления), live-превью A4.
- **Авто-реквизиты и реестр исходящих** (`9244417`): уникальный исходящий номер (код отдела + дата +
  номер), регистрация в реестре, строгий учёт счётчиков.
- **Цифровая подпись по ГОСТ** с форматированием и штампами (`9244417`).
- **Справочник сотрудников** с подстановкой должности в дательном падеже и автодополнением адресата
  (`1610360`, `c15111e`).
- **Автосклонение ФИО и должностей** для русских падежей — offline, правила + словари, без внешних API
  (`e9f3d89`, `9244417`).
- **Реестр**: поиск, фильтр по отделу и периоду, экспорт CSV, печать, дашборд статистики
  (`39ae8f0`, `3be0e19`, `7b1c3dc`).
- **Hash-chain целостность реестра** (FNV-1a 64, `hash` + `prevHash`): обнаружение правок в обход
  приложения, миграция старых записей, перестройка цепочки администратором (`a18cc69`).
- **Слой хранения реестра** (`registryStorage`) с абстракцией под базу tmdata (`0460376`).
- **Экспорт**: PDF (jsPDF), `.eml` для Outlook, печать, копирование текста; SVG-печать, сканы подписей.
- **Черновики** с версиями `major.minor` и историей (`c15111e`).
- **Шаблоны писем**: готовые каркасы документов (запрос КП, уведомление, приказ …) (`a169782`).
- **Роли** пользователь / администратор с подписанным хранилищем роли (`7d6681f`) — deterrent, не криптозащита (см. README).
- **Инлайн-валидация** формы и валидация массовых адресатов (`c697310`).
- **Автосохранение** с debounce и мемоизированное превью (`d8a608a`).
- **Electron-сборка (portable .exe)** и локальный режим без портала/сети (`c1a9aeb`, `92e61ad`).
- **Микросервисный деплой**: `deploy_docgen.sh`, `prod.sh`, systemd-юнит, nginx под префиксом `/docgen/`
  (`26a58fc`, `deed972`, `9295181`, `e43c5b9`).
- **README** (режимы, возможности, hash-chain, роли, деплой, структура) (`98654bc`, `c2c82e7`).
- **Vitest-набор** (7 файлов, 86 тестов) (`a18cc69`, `a169782`).
- `LICENSE` (проприетарная, внутренняя) и CI workflow (`npm ci` → `tsc --noEmit` → `vitest run`).

### Changed

- Офлайн-режим: удалены Gemini API и зависимость `@google/genai` (`1223f93`).
- Удалены неиспользуемые PDF-зависимости и мёртвый код: `xlsx`, `pdf-lib`, `jspdf`, `html2canvas`,
  бутафорский dynamic import `jsbarcode`, неиспользуемый `motion` (`1b324f7`, `3272dd3`, `7602428`).
- Удалён таб «Оформление» (настройка полей и шрифтов) (`cf15f2b`), удалён неиспользуемый templates modal,
  из пресетов убраны вымышленные сотрудники (`870fee0`, `49b0165`).
- Чекаут деплоя перенесён из домашнего каталога в рабочий каталог рантайма, юнит systemd
  синхронизируется автоматически (`ab478f5`, `518c517`, `5ad04b0`).

### Fixed

- Hash-chain реестра ломался из-за `undefined` в `digitalSignatureKey` (`462b8a9`).
- Кнопка «Вернуться на портал» ничего не делала вне iframe (`29ea273`).
- Синтаксическая ошибка в `AuthModal`, восстановление константы базы сотрудников (`0e90f6c`).
- Пин `@tailwindcss/oxide-linux-x64-gnu` — тот же npm-баг `npm/cli#4828`, что и в filter-app-graphs (`f60c6c0`).
- Отсутствующий импорт `useRef` и выравнивание полей `DocumentVersion` (`5ffff3b`).
